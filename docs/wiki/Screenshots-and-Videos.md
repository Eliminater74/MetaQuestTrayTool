## Quest screenshots

Screenshot PNGs are written to `%AppData%\MetaQuestTrayTool\screenshots\`.

### Smart screenshot

Use tray → **Screenshots → Take screenshot (Quest Link preferred)**, **Ctrl+Shift+Num 8**, or voice **take screenshot** / **capture screenshot** / **save screenshot**. The app captures the Quest Link / Air Link mirror when an active Meta Link stream is detected, then falls back to the trusted-headset ADB path.

### Quest Link mirror screenshot

Use tray → **Screenshots → Take Quest Link mirror screenshot**, the **Quest Link** page button, or voice **take link screenshot** / **quest link screenshot** / **mirror screenshot**. This uses Meta's `OculusMirror.exe`, requires an active Quest Link / Air Link stream, and does not require ADB.

### Headset ADB screenshot

Use tray → **Screenshots → Take headset screenshot (ADB)**, tray → **Headset (ADB) → Take headset screenshot (ADB)**, the **Headset** page button, **Ctrl+Shift+Num 9**, or voice **take headset screenshot** / **quest screenshot** / **ADB screenshot**. This requires a trusted, ready Quest over USB or wireless ADB and validates the PNG before reporting success.

When **Speak status in headset** can reach the Quest audio path, the app says **“Screenshot taken.”** after the file is saved.
